# Dynamic Wave для Windows

## Запуск
Двойной клик по **Запустить.vbs**. Иконка появится в трее: клик открывает настройки, правый клик открывает меню с пунктом «Выход».

## Управление
- **Навести мышь** на остров: раскрыть его.
- **Колёсико мыши**: листать страницы (часы, музыка/видео, ЦП/ОЗУ, календарь, Discord).
- **Правый клик** по острову: настройки.
- **Клик по уведомлению о скриншоте**: открыть файл.

## Что показывает
- Время, дата, мини-нагрузку ЦП, оранжевую точку, когда какая-то программа использует микрофон.
- Музыку и видео из любого плеера и браузера (YouTube, Spotify, Яндекс Музыка…): обложку, прогресс и кнопки управления. Акцентный цвет берётся из обложки (можно выключить в настройках).
- Уведомления: скопирован текст, ссылка, картинка или файл, сохранён скриншот (папка «Изображения\Screenshots»).
- Discord: кто говорит в голосовом канале (нужна разовая настройка, инструкция есть в окне настроек).
- Погода (Open-Meteo, без ключа): температура в свёрнутом острове и отдельная страница с прогнозом на 5 часов. Город задаётся в настройках, по умолчанию определяется по IP.
- Сообщения из Telegram, Discord и почты: остров раскрывается в карточку с аватаркой, отправителем и текстом. Берутся из базы уведомлений Windows, поэтому уведомления Windows должны быть включены (баннеры можно выключить).
- Wave correction: подсказка, если слово набрано не в той раскладке (ghbdtn → привет, руддщ → hello). Работает локально через Windows UI Automation, текст не сохраняется. Настройки: трей → Wave correction. Горячая клавиша Ctrl+Shift+Space, Esc закрывает подсказку.
- Смена раскладки (RU / EN) и Caps Lock; пока Caps Lock включён, в свёрнутом острове горит значок.

## Файлы
- `main.js`: окно, трей, буфер обмена, скриншоты, настройки
- `src/helper.ps1`: медиа (Windows SMTC), микрофон, процессы
- `src/discord.js`: Discord RPC
- `src/weather.js`: погода (Open-Meteo)
- `src/smartlayout/`: Wave correction (движок, словари, монитор ввода UI Automation, сервис)
- `src/winnotify.js`: чтение уведомлений Windows (wpndatabase.db через sql.js)
- `renderer/`: интерфейс острова и окна настроек

## Тесты
- `npm test`: движок и сервис Wave correction (без Windows API)
- `npm run test:uia`: интеграционный тест с настоящим полем ввода Windows (открывает своё окно на ~20 секунд)
- `npm run calibrate`: калибровка порогов на словарях
