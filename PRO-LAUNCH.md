# Wave Pro — подготовка запуска

Версия 1.9.0 содержит бесплатные ограничения, новые темы, экран предложения и проект оферты. Продажи пока закрыты. Кнопка покупки сообщает об этом и не активирует Pro.

## Перед открытием продаж

1. Указать продавца, налоговый статус, ИНН, адрес и поддержку; завершить оферту `renderer/offer.html` и отдельную политику обработки персональных данных.
2. Выбрать оператора платежей и развернуть HTTPS-сервер. Секрет платёжного API и закрытый ключ лицензирования хранятся только на сервере.
3. Реализовать учёт пользователей, создание оплаты 99 RUB, проверку её статуса непосредственно у оператора, идемпотентную обработку уведомлений, выдачу доступа и возвраты. Переход по return URL сам по себе не подтверждает оплату.
4. Подключить приложение к серверу: вход, покупка, восстановление доступа, получение лицензии и проверка статуса. Сейчас этих сетевых маршрутов нет. Не включать `paymentReady` до завершения всей цепочки.
5. Сервер подписывает Ed25519 исходную строку JSON `payload` с `{ product: "wave-pro", expiresAt: <UTC timestamp milliseconds> }`. Приложение проверяет подпись `signature` (base64) публичным ключом из `src/pro-config.json`. Файл `pro-license.json` в userData содержит обе строки. Текущий формат — заготовка: перед продажами добавить привязку к аккаунту/установке, срок офлайн-проверки и отзыв лицензии; иначе подписанную лицензию можно копировать между ПК.
6. Лимит 15 успешных переводов в календарный месяц Europe/Moscow хранится локально отдельно от настроек. Это ограничение интерфейса продукта, а не защита от удаления данных или изменения системных часов. Для надёжного учёта перенести квоту на сервер.
7. При автопродлении реализовать отдельное согласие, отмену, отказ от использования платёжных реквизитов, чеки, возвраты и уведомления. В этой версии рекуррентных списаний нет.
8. Проверить полный цикл тестовой покупки, отказа/ошибки платежа, повторных уведомлений, активации, окончания срока, восстановления покупки и возврата до подключения боевой кассы.

Стандартные темы остаются бесплатными. Платные: ruby, ocean, forest, amethyst, custom. Бесплатные голосовые действия: play, next, prev, vol_up, vol_down, mute. Обновления приложения общие; отдельного бинарного файла Pro нет, возможности включаются лицензией.
